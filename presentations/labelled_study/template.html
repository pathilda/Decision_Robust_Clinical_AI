Step 1 · ICFThe WHO International Classification of Functioning (ICF)

What it is

A WHO framework (2001; children & youth version 2007) that describes functioning, not diagnoses. Health is the interaction of body functions, activities and participation with contextual factors (the biopsychosocial model).

Generic qualifier (severity)

0no problem
1mild
2moderate
3severe
4complete
8not specified
9n/a

Environmental factors: direction (barrier / facilitator) × magnitude 0–4.

The targetFive complexity classes

one area of need · straightforward planmore domains · contextual barriers · coordination with other providers

Each class score sk is the client's complexity in the decision model. Two or more areas of need count as multiple domains. Hover a class for the clinical team's full definition.

EvaluationHow each configuration is scored

Three load profiles · clinicians A, B, C

Decision regret (lower is better)

R = Range(x̂; s*) − minx Range(x; s*)

Range = largest minus smallest final caseload complexity. s* = clinician class scores. 0 means the decision is as balanced as the clinician-label optimum.

Assignment agreement (%)

Share of clients sent to the same clinician as a fixed clinician-optimal reference allocation.

Class agreement and QWK

LLM class vs. clinician class (distribution: most likely class; score: nearest class score).

Feasibility

LLM full allocations must assign every client exactly once within each clinician's capacity.

Equal-complexity benchmark (dashed line in the results)

The same OR model with every client given the same complexity, so it only balances client counts. An assessment adds value only if it beats this line.
